# Sitemap & robots.txt Audit Report

**Date:** 2026-04-09  
**Site:** https://juan-tech.com  
**Repository:** JuanPortfolio (develop branch)

---

## Executive Summary

The sitemap infrastructure has CRITICAL issues. The static `public/sitemap.xml` generated by `next-sitemap` contains only 1 URL (robots.txt!) and zero actual content pages. The site relies on 4 dynamic SSR sitemap routes that are **not referenced** from the static sitemap index. This means Google may never discover the dynamic sitemaps unless it follows links or finds them elsewhere.

---

## 1. Static Sitemap Analysis (`public/sitemap.xml`)

### CRITICAL: Sitemap is effectively empty

**Contents:** Single `<url>` entry pointing to `https://juan-tech.com/robots.txt`

**Issues:**

| Check | Status | Details |
|-------|--------|---------|
| Valid XML | PASS | Well-formed XML with proper namespace |
| URL count | FAIL | 1 URL (only robots.txt) -- should have 100+ |
| Content pages included | FAIL | Zero blog posts, zero pages, zero categories |
| lastmod accuracy | FAIL | `2026-04-09T16:45:24.080Z` -- looks auto-generated, not real modification date |
| changefreq tag | INFO | Present (`daily`) -- ignored by Google, can remove |
| priority tag | INFO | Present (`0.7`) -- ignored by Google, can remove |
| Unnecessary namespaces | LOW | Declares news, xhtml, mobile, image, video namespaces but uses none |
| Under 50k URL limit | PASS | 1 URL (trivially passes) |

**Root cause:** `next-sitemap` runs as `postbuild` but only discovers statically rendered routes. Since the site uses dynamic SSR routes from Payload CMS, `next-sitemap` finds almost nothing. The config has `generateIndexSitemap: false`, so there is no sitemap index pointing to the dynamic sitemaps.

### `public/sitemap-0.xml`

Identical content to `sitemap.xml` -- a redundant duplicate with the same single robots.txt URL.

| Check | Status | Details |
|-------|--------|---------|
| Discoverable from sitemap.xml | FAIL | Not referenced anywhere in sitemap.xml or robots.txt |

- Handles pages, posts, case-studies collections
- Respects `noindex` and `excludeFromSitemap` settings
- Does NOT appear to be registered as an active endpoint (no evidence it's mounted)

This appears to be dead code or a previous implementation superseded by the `next-sitemap` + SSR routes approach.

## 4. robots.txt Analysis (`public/robots.txt`)

```
User-agent: *
Allow: /

Host: https://juan-tech.com

Sitemap: https://juan-tech.com/sitemap.xml
```

### Issues

| Check | Status | Details |
|-------|--------|---------|
| User-agent coverage | PASS | Wildcard `*` covers all bots |
| Allow directive | PASS | Allows all paths |
| Admin blocked | FAIL | `/admin` and `/admin/*` are NOT blocked (only excluded from next-sitemap, not robots.txt) |
| API routes blocked | FAIL | `/api/*` not blocked -- Payload CMS API endpoints are crawlable |
| Sitemap reference | PARTIAL | Points to empty static sitemap, missing dynamic sitemaps |
| Host directive | INFO | Non-standard directive; some bots ignore it. Not harmful. |
| Dynamic sitemaps listed | FAIL | Should list all 4 dynamic sitemaps |
| next-sitemap generates robots.txt | CONFLICT | `generateRobotsTxt: true` in config, but the committed robots.txt differs from what next-sitemap would produce |

### Missing Disallow rules (recommended)

- `/admin` -- Payload CMS admin panel
- `/api/*` -- Payload REST API endpoints
- `/_next/*` -- Next.js internal routes (static assets already have cache headers)
- `/search` -- Search pages typically have no SEO value when indexed

## 6. Conflicts Between Sitemap and robots.txt

1. **robots.txt points to empty sitemap** -- Google follows the Sitemap directive, finds 1 useless URL, and has no map to the actual content.
2. **No Disallow for admin/api** -- Crawler budget is wasted on non-content URLs, and sensitive admin endpoints are indexable.
3. **next-sitemap config excludes `/admin`** from sitemap generation but does NOT add it to robots.txt Disallow.

---

## 7. Recommendations (Priority Order)

### CRITICAL

1. **Add dynamic sitemaps to robots.txt** -- Add all 4 SSR sitemap URLs:
   ```
   Sitemap: https://juan-tech.com/posts-sitemap.xml
   Sitemap: https://juan-tech.com/pages-sitemap.xml
   Sitemap: https://juan-tech.com/categories-sitemap.xml
   Sitemap: https://juan-tech.com/authors-sitemap.xml
   ```

2. **Fix or replace static sitemap.xml** -- Either:
   - Convert it to a sitemap index that references the 4 dynamic sitemaps, OR
   - Remove it and rely solely on the Sitemap directives in robots.txt

3. **Create case-studies sitemap route** -- Missing SSR sitemap for the `case-studies` collection.

### HIGH

4. **Block admin and API in robots.txt**:
   ```
   Disallow: /admin
   Disallow: /api/
   ```

5. **Fix SITE_URL fallback** -- Replace `https://example.com` fallback with `https://juan-tech.com` in all 4 SSR sitemap routes.

6. **Remove `public/sitemap-0.xml`** -- Redundant file with no value.

### MEDIUM

7. **Remove deprecated tags from static sitemap** -- `changefreq` and `priority` are ignored by Google.

8. **Clean up unused namespaces** in static sitemap XML header (news, mobile, video, image are declared but unused).

9. **Remove or archive legacy Payload sitemap endpoint** (`src/plugins/seo/endpoints/sitemap.ts`) if it's not actively mounted.

### LOW

10. **Add `noindex` check to SSR sitemaps** -- The dynamic sitemaps don't filter out posts with `meta.noindex: true` (the legacy endpoint does).

11. **Consider adding `<xhtml:link>` hreflang annotations** in the post sitemap for proper multilingual SEO signaling.

12. **Update next-sitemap config** -- Either leverage it properly by adding `additionalSitemaps` to reference the dynamic ones, or remove the dependency if it's not adding value.
