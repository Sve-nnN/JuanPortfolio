## 1. Descripción del Producto

Paquete de templates profesionales de Notion diseñados específicamente para profesionales de SEO técnico y desarrolladores que necesitan sistematizar sus auditorías, seguimiento de keywords y planificación de contenido.

### ¿Por qué funciona?

- **Notion tiene 100M+ usuarios** y su marketplace de templates está creciendo rápidamente
- Los profesionales de SEO y desarrollo ya usan Notion para documentación
- Existe demanda real: "seo notion template" y "notion template for developers" tienen volúmenes de búsqueda crecientes
- El contenido del blog de juan-tech.com demuestra la metodología → cada artículo es un anuncio del template

### Ventaja competitiva

Los templates de SEO que existen en el mercado son genéricos y para marketers. Los templates de Juan están diseñados por un ingeniero de software que hace SEO técnico real: incluyen aspectos técnicos (Core Web Vitals, Schema, indexabilidad) que ningún otro template cubre.

## 2. Templates a Crear

### Template A: "Technical SEO Audit Dashboard" (EN)
**Precio:** $29 USD

#### Contenido
- **Database de auditoría:** Tabla maestra para trackear issues de SEO técnico (crawl errors, indexación, performance, schema, seguridad)
- **Vistas por severidad:** Critical / Warning / Info / Fixed — con filtros automáticos
- **Vistas por tipo:** Crawlability, Indexability, Performance, Schema, Content
- **Sección de Screenshots y Evidencia:** Campo para subir capturas de GSC, Lighthouse, Screaming Frog
- **Checklist de Auditoría Técnica:** 50+ items pre-cargados cubriendo:
  - Robots.txt y Sitemaps
  - Core Web Vitals (LCP, CLS, INP)
  - Schema.org y datos estructurados
  - Canonical y redirecciones
  - HTTPS y seguridad
  - Hreflang y localización
- **Report Generator:** Template de informe ejecutivo con formato profesional
- **Guía de uso:** Documentación paso a paso de cómo ejecutar una auditoría completa

#### Keywords que atrae
- "seo audit template notion" (~200/mes)
- "technical seo checklist" (2,700/mes US, KD 24)
- "seo audit dashboard"

### Template C: "Content Strategy Planner — Topic Clusters Edition" (EN)
**Precio:** $35 USD

#### Contenido
- **Topic Cluster Mapper:** Base de datos relacional para mapear pillar pages ↔ satellite pages
- **Keyword Research Database:** Tabla con campos para keyword, volumen, KD, intención, estado, URL
- **Content Calendar:** Vista de calendario con pipeline editorial (Idea → Research → Draft → Review → Published)
- **Internal Linking Matrix:** Tabla para planificar enlaces internos entre clusters
- **Content Performance Tracker:** Campos para tráfico, rankings, backlinks, actualizaciones pendientes
- **Content Refresh Schedule:** Automatización para recordar cuándo actualizar cada artículo (>6 meses)
- **Guía de Estrategia de Contenidos:** Documento de 10 páginas explicando la metodología de topic clusters

#### Keywords que atrae
- "content strategy notion template" (~400/mes)
- "seo content strategy" (4,100/mes US, KD 8)
- "topic cluster template" (~100/mes)

### Template D: "Core Web Vitals Monitoring Tracker" (EN/ES)
**Precio:** $19 USD

#### Contenido
- **Dashboard de monitoreo:** Tabla para registrar métricas de LCP, CLS, INP, TTFB por URL
- **Comparativa mes a mes:** Vistas para visualizar tendencias de performance
- **Threshold alerts:** Alertas visuales cuando las métricas superan los límites de Google
- **Action Log:** Registro de acciones tomadas y su impacto en métricas
- **Integración con datos de GSC:** Campos para importar datos de Core Web Vitals desde Search Console
- **Checklist de optimización:** 30+ acciones para mejorar performance web
- **Disponible en inglés y español**
