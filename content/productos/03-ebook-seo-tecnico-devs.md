## 1. Descripción del Producto

Un ebook (o video-curso) que compila y estructura todo el conocimiento de SEO técnico del blog de juan-tech.com en un formato cohesivo, diseñado específicamente para desarrolladores que quieren entender SEO sin el lenguaje de marketing.

### ¿Por qué funciona?

- El contenido **ya existe** en el blog — es cuestión de compilar, editar y estructurar
- **"technical seo guide"** tiene 600 búsquedas/mes en US (KD 75) y 450/mes en ES (KD 2-5)
- **No existe un buen libro de SEO técnico en español orientado a developers**
- Los ebooks de calidad en Gumroad se venden por años con mínimo mantenimiento
- El ebook es un lead magnet natural para los servicios de consultoría

### Ventaja competitiva

Todos los libros de SEO existentes están escritos por marketers, no por ingenieros. Este ebook incluye fragmentos de código real, configuraciones de Next.js, ejemplos de schema en JSON-LD, y métricas de Core Web Vitals interpretadas desde la perspectiva de un developer.

## 3. Estructura del Ebook

### Parte 1: Fundamentos del SEO Técnico (40 páginas)

**Capítulo 1: Por qué el SEO técnico importa (y por qué los devs son los mejores para hacerlo)**
- La brecha entre SEOs y developers
- Cómo Google rastrea, indexa y rankea
- El rol del developer en el SEO moderno

**Capítulo 2: Arquitectura web para SEO**
- Estructura de URLs y jerarquía de contenido
- Diseño de información para rastreabilidad
- Sitemaps XML: generación y buenas prácticas
- Robots.txt: qué bloquear y qué no

**Capítulo 3: Renderizado y SEO**
- CSR vs SSR vs SSG vs ISR: qué significa cada uno para Google
- Cómo Google renderiza JavaScript
- Next.js App Router y estrategias de renderizado
- Hidratación y su impacto en SEO

### Parte 2: Auditoría Técnica (50 páginas)

**Capítulo 4: Metodología de auditoría técnica**
- Framework de auditoría de 5 fases
- Herramientas: Google Search Console, Screaming Frog, Lighthouse
- Cómo leer un log file de servidor

**Capítulo 5: Core Web Vitals para developers**
- LCP: optimización de imágenes, fuentes, render-blocking
- CLS: dimensiones explícitas, font-display, layouts estables
- INP: long tasks, code splitting, web workers
- Ejemplos de código Next.js para cada métrica

**Capítulo 6: Schema.org y datos estructurados**
- JSON-LD: implementación práctica
- Tipos esenciales: Article, BreadcrumbList, FAQPage, Person, Organization
- Cómo validar schema y monitorear rich results
- Ejemplos de schema dinámico en Next.js

### Parte 3: Estrategia de Contenido Técnico (40 páginas)

**Capítulo 7: Topic Clusters y Autoridad Tópica**
- Arquitectura pillar-satellite
- Cómo planificar un cluster de contenido
- Internal linking estratégico con código
- Canibalización de keywords: detección y solución

**Capítulo 8: SEO On-Page para developers**
- Title tags y meta descriptions dinámicos
- Heading hierarchy y accesibilidad
- Imágenes: alt text, formatos AVIF/WebP, lazy loading
- Open Graph y Twitter Cards

**Capítulo 9: SEO Internacional**
- Hreflang: implementación en Next.js con middleware
- Estrategia bilingüe ES/EN
- Canonical y alternates

### Parte 4: Performance y Automatización (40 páginas)

**Capítulo 10: Automatización de SEO en CI/CD**
- Lighthouse CI en GitHub Actions
- Tests de SEO automatizados
- Monitoreo de Core Web Vitals en producción

**Capítulo 11: Migraciones sin perder tráfico**
- Checklist de migración
- Redirecciones 301 y mapeo de URLs
- Cómo monitorear después de una migración

**Capítulo 12: El futuro del SEO para developers**
- AI Overviews y Generative Engine Optimization (GEO)
- Cómo preparar contenido para ser citado por LLMs
- Tendencias 2026-2027

### Apéndices
- A: Checklist de lanzamiento SEO (1 página imprimible)
- B: Configuración de referencia de next.config.js para SEO
- C: Ejemplos de schema JSON-LD (copiar y pegar)
- D: Glosario de términos SEO para developers

## 8. Plan de Acción

### Fase 1: Compilación (20h)
1. Extraer los 12 mejores artículos de SEO técnico del blog
2. Organizarlos según la estructura de capítulos
3. Identificar gaps (temas que faltan)
4. Escribir el contenido faltante

### Fase 2: Edición (15h)
1. Unificar tono y estilo entre capítulos
2. Estandarizar fragmentos de código (mismo formato, mismos comentarios)
3. Crear gráficos y diagramas (arquitectura de clusters, flujo de auditoría)
4. Revisión técnica (verificar que el código funciona en 2026)

### Fase 3: Diseño (10h)
1. Diseñar portada profesional (contratar en Fiverr si es necesario: $30-80)
2. Maquetar en formato PDF (herramienta: Google Docs → PDF o Figma → PDF)
3. Crear versión EPUB
4. Configurar página de producto en Gumroad

### Fase 4: Lanzamiento (5h)
1. Publicar en Gumroad
2. Crear landing page en juan-tech.com
3. Campaña de lanzamiento en redes
