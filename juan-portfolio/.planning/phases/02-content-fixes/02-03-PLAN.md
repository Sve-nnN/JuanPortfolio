<task type="auto">
  <name>Task 2: Fix all meta description issues and update audit report</name>
  <files></files>
  <action>
    For each post flagged as MISSING, TOO_SHORT, or TOO_LONG in Task 1:

    **Step A — Write a new meta description:**
    The meta description must be 120-160 characters, Spanish for ES posts / English for EN posts.
    Write a compelling, informative description that:
    - Summarizes the post's main topic accurately
    - Contains the primary keyword naturally
    - Is exactly 120-160 characters (count carefully)
    - Does NOT start with "Descubre" or "Learn about" (overused patterns)

    **Step B — Apply the fix:**
    If the post has a markdown source file in content/posts/:
      1. Read the file.
      2. Update `metaDescription:` in the frontmatter to the new value.
      3. Write the file back.
      4. Run: pnpm sync push -- --post=<filename.md>

    If no markdown source (CMS-only record):
      Update via Payload MCP: set meta.description on the post record directly.

    **Step C — Update meta-audit-report.md:**
    After fixing all issues, update the "Fixes Applied" section of the report with a list of
    every post fixed and the new meta description text used.

    Important: Do NOT change any frontmatter field other than `metaDescription`.
    Do NOT touch draft posts (development/ articles from 02-02 are draft — skip them).
