Create `src/app/api/internal-links/apply/route.ts`:

1. Auth check (same pattern as GET route).

2. Parse body: `const body: ApplyLinkBody = await req.json()`.
   Validate all required fields present; return 400 if any missing.

3. Path traversal guard:
   ```typescript
   import * as path from 'path'
   const contentRoot = path.resolve(process.cwd(), 'content')
   const resolvedPath = path.resolve(body.filePath)
   if (!resolvedPath.startsWith(contentRoot)) {
     return NextResponse.json({ error: 'Invalid file path' }, { status: 403 })
   }
   ```

4. Check file exists using `fs.existsSync(resolvedPath)`. Return 400 if not.

5. Read the file: `const raw = fs.readFileSync(resolvedPath, 'utf-8')`.

6. Apply the link inline — find the line at `body.lineNumber` (1-based), find the first occurrence of `body.keyword` on that line that is NOT already inside a markdown link (`[...](...)` pattern), and replace it with `[${body.keyword}](${body.targetUrl})`:

   ```typescript
   import matter from 'gray-matter'
   const { data: frontmatter, content: body: bodyText } = matter(raw)
   const lines = bodyText.split('\n')
   const lineIdx = body.lineNumber - 1  // lineNumber is relative to body, not file
   // Find the line and replace first unlinked keyword occurrence
   // Use a regex that avoids already-linked text: negative lookbehind for ']('
   const replaced = lines[lineIdx].replace(
     new RegExp(`(?<!\\[)(?<![\\w/])${escapeRegex(body.keyword)}(?![\\w])(?![^\\[]*\\])`, 'i'),
     `[${body.keyword}](${body.targetUrl})`
   )
   lines[lineIdx] = replaced
   const newContent = matter.stringify(lines.join('\n'), frontmatter)
   fs.writeFileSync(resolvedPath, newContent, 'utf-8')
   ```

   Add a local `escapeRegex(str: string): string` helper that escapes special regex chars.

7. Run sync push via spawnSync (same pattern used by create-post.ts):
   ```typescript
   import { spawnSync } from 'child_process'
   const syncResult = spawnSync('pnpm', ['sync', 'push', '--', `--post=${path.basename(resolvedPath)}`], {
     cwd: process.cwd(),
     stdio: 'pipe',
     encoding: 'utf-8',
   })
   if (syncResult.status !== 0) {
     return NextResponse.json({
       success: false,
       message: 'Link written but sync failed',
       error: syncResult.stderr || syncResult.stdout,
     })
   }
   ```

8. Return `200 { success: true, message: 'Link applied and synced' }`.

Wrap entire handler in try/catch returning 500 on unexpected errors.
