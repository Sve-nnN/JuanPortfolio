# Estrategia y Plan de Contenidos: Desarrollo y SEO Técnico

Este documento detalla la estrategia de contenidos para posicionar a **JuanPortfolio** como una referencia mundial en Desarrollo de Software y SEO Técnico.

> **Nota Importante:** El seguimiento detallado de métricas de palabras clave (volumen, dificultad, etc.) se gestiona en el archivo separado: [`keywords.md`](./keywords.md).

**Objetivo Principal:** Convertirse en una autoridad de nicho en la intersección entre ingeniería de software y optimización para motores de búsqueda (Technical SEO).

---

## 1. Estrategia de Contenidos

Nuestra estrategia se basa en tres pilares fundamentales para cubrir todo el espectro de conocimiento necesario para un desarrollador full-stack moderno con enfoque en SEO.

### Pilar A: Ingeniería de SEO Técnico (El Diferenciador)
*Enfoque:* Cómo los desarrolladores pueden influir directamente en el SEO.
*   **Temas Clave:** Core Web Vitals, SSR/CSR, Performance.
*   **Intención:** Informacional / Educativa (High intent).

### Pilar B: Ciencias de la Computación (Fundamentos Universitarios)
*Enfoque:* Explicaciones profundas y académicas pero accesibles.
*   **Temas Clave:** Algoritmos, Estructuras de Datos, Bases de Datos.
*   **Intención:** Educativa / Académica.

### Pilar C: El Stack Moderno (Next.js + PayloadCMS)
*Enfoque:* Tutoriales prácticos y "How-to" de la tecnología que usas.
*   **Temas Clave:** PayloadCMS, Next.js, Headless CMS.
*   **Intención:** Transaccional / Implementación práctica.

### Pilar D: SEO Estratégico y de Contenidos (Autoridad Tópica)
*Enfoque:* Estrategias de posicionamiento más allá del código.
*   **Temas Clave:** Topic Clusters, Keyword Research, E-E-A-T, Redacción SEO.
*   **Intención:** Informacional / Estratégico.

## 2. Estrategia de Categorías (URL Structure)

Para mejorar la organización semántica y el SEO, utilizaremos la estructura de URLs: `juan-tech.com/[category]/[slug]`.

| Categoría           | Slug              | Descripción                                                           | Pilar Relacionado |
| :------------------ | :---------------- | :-------------------------------------------------------------------- | :---------------- |
| **Technical SEO**   | `tech-seo`        | Guías avanzadas de SEO técnico, performance y optimización.           | Pilar A           |
| **CS Fundamentals** | `cs-fundamentals` | Artículos académicos sobre algoritmos, estructuras de datos y teoría. | Pilar B           |
| **Development**     | `development`     | Tutoriales de Next.js, PayloadCMS y desarrollo web moderno.           | Pilar C           |
| **SEO**             | `seo`             | Estrategia de contenidos, autoridad tópica y marketing SEO.           | Pilar D           |

## 3. Topic Clusters (Plan Escalable)

Utilizamos "Clusters" para organizar el contenido y construir autoridad tópica.

### Cluster 1: Rendimiento Web y Core Web Vitals
*   **Pillar Page:** La Guía Completa de Web Performance para Desarrolladores.
*   **Content:** LCP, CLS, INP, Optimización de imágenes, Lazy loading.

### Cluster 2: Fundamentos de Ingeniería de Software
*   **Pillar Page:** Ciencias de la Computación: De la Teoría a la Práctica.
*   **Content:** Big O Notation, Estructuras de Datos, Algoritmos de búsqueda, SQL vs NoSQL, ACID.

### Cluster 3: Arquitectura Técnica SEO
*   **Pillar Page:** Arquitectura de Software Amigable con SEO.
*   **Content:** Rendering Patterns, Rutas dinámicas, Canonical Tags, i18n, Schema.org.

### Cluster 4: Dominio de Autoridad Tópica
*   **Pillar Page:** Estrategia Maestra de Topic Clusters y Contenido.
*   **Content:** Keyword Research, Redacción SEO, E-E-A-T, Link Building Interno.

## 5. Flujo de Trabajo para Nuevo Contenido

1.  **Investigación:**
    *   Consulta [`keywords.md`](./keywords.md) para elegir una palabra clave.
    *   Ejecuta el script de métricas para obtener datos actualizados.

2.  **Estructura (Outline):**
    *   Define H1 y H2s basados en la intención de búsqueda.

3.  **Redacción y Código:**
    *   Prioriza ejemplos de código reales y explicaciones técnicas profundas.

4.  **Optimización:**
    *   Verifica meta tags, URLs y enlaces internos.
