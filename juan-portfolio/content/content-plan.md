# Estrategia y Plan de Contenidos: Desarrollo y SEO Técnico

Este documento detalla la estrategia de contenidos para posicionar a **JuanPortfolio** como una referencia mundial en Desarrollo de Software y SEO Técnico.

> **Nota Importante:** El seguimiento detallado de métricas de palabras clave (volumen, dificultad, etc.) se gestiona en el archivo separado: [`keywords.md`](./keywords.md).

**Objetivo Principal:** Convertirse en una autoridad de nicho en la intersección entre ingeniería de software y optimización para motores de búsqueda (Technical SEO).

---

## 1. Estrategia de Contenidos

Nuestra estrategia se basa en tres pilares fundamentales para cubrir todo el espectro de conocimiento necesario para un desarrollador full-stack moderno con enfoque en SEO.

### Pilar A: Ingeniería de SEO Técnico (El Diferenciador)
*Enfoque:* Cómo los desarrolladores pueden influir directamente en el SEO.
*   **Temas Clave:** Core Web Vitals, SSR/CSR, Performance.
*   **Intención:** Informacional / Educativa (High intent).

### Pilar B: Ciencias de la Computación (Fundamentos Universitarios)
*Enfoque:* Explicaciones profundas y académicas pero accesibles.
*   **Temas Clave:** Algoritmos, Estructuras de Datos, Bases de Datos.
*   **Intención:** Educativa / Académica.

### Pilar C: El Stack Moderno (Next.js + PayloadCMS)
*Enfoque:* Tutoriales prácticos y "How-to" de la tecnología que usas.
*   **Temas Clave:** PayloadCMS, Next.js, Headless CMS.
*   **Intención:** Transaccional / Implementación práctica.

### Pilar D: SEO Estratégico y de Contenidos (Autoridad Tópica)
*Enfoque:* Estrategias de posicionamiento más allá del código.
*   **Temas Clave:** Topic Clusters, Keyword Research, E-E-A-T, Redacción SEO.
*   **Intención:** Informacional / Estratégico.

### Pilar E: Contenido "Hero" o "Linkbait" (Autoridad de Marca)
*Enfoque:* Investigación original y estudios de datos para atraer backlinks.
*   **Temas Clave:** Estudios de campo, auditorías masivas, experimentos de código.
*   **Intención:** Link Building natural / Autoridad de industria.

## 3. Topic Clusters (Plan Escalable)

Utilizamos "Clusters" para organizar el contenido y construir autoridad tópica. Cada cluster tiene una "Pillar Page" que actúa como hub central y múltiples "Satellite Pages" que profundizan en sub-temas específicos.

### Cluster: Dominio de Autoridad Tópica (SEO)
- **Estrategia a Cumplir:** Establecer a JuanPortfolio como el recurso de referencia en español para la estrategia de contenido SEO moderna. La Pillar Page debe actuar como el manifiesto central, mientras que los satélites proporcionan las guías tácticas y accionables para ejecutar cada fase de la estrategia. Todos los satélites deben enlazar de vuelta al pilar.

- **Pillar Page:**
  - `estrategia-topic-clusters.md` (Actúa como la guía arquitectónica principal).

- **Satellite Pages:**
  - `guia-keyword-research.md` (Fase 1: Investigación y Oportunidad).
  - `redaccion-seo.md` (Fase 2: Creación y Optimización para IA).
  - `guia-eeat.md` (Fase 3: Capa de Autoridad y Confianza).
  - `enlaces-internos-guia.md` (Fase 4: Conexión y Distribución de Autoridad).

### Cluster: Fundamentos de Ingeniería de Software (CS)
- **Estrategia a Cumplir:** Convertirse en la guía universitaria de referencia sobre Ciencias de la Computación, explicando conceptos complejos de manera clara y con ejemplos prácticos. La Pillar Page debe ofrecer una visión general completa, y cada satélite debe ser un deep-dive exhaustivo en su respectivo tema, todos interconectados para facilitar un aprendizaje completo.

- **Pillar Page:**
  - `algoritmos-estructuras-datos.md` (Es la guía más completa que introduce todos los demás conceptos).

- **Satellite Pages:**
  - `complejidad-algoritmica.md` (Profundiza en la medición del rendimiento).
  - `big-o-notation.md` (El lenguaje para hablar de complejidad).
  - `algoritmos-ordenamiento.md` (Un caso de estudio práctico de algoritmos).
  - `arboles-binarios.md` (Una estructura de datos fundamental).
  - `programacion-dinamica.md` (Una técnica de optimización avanzada).
  - `diseno-bases-datos.md` (Aplicación de estructuras de datos al almacenamiento).
  - `normalizacion-bases-datos.md` (Principios de diseño para la integridad de datos).

### Cluster: Arquitectura Técnica SEO

## 6. Flujo de Trabajo para Nuevo Contenido

1.  **Investigación:**
    *   Consulta [`keywords.md`](./keywords.md) para elegir una palabra clave.
    *   Ejecuta el script de métricas para obtener datos actualizados.

2.  **Estructura (Outline):**
    *   Define H1 y H2s basados en la intención de búsqueda.

3.  **Redacción y Código:**
    *   Prioriza ejemplos de código reales y explicaciones técnicas profundas.

4.  **Optimización:**
    *   Verifica meta tags, URLs y enlaces internos.
