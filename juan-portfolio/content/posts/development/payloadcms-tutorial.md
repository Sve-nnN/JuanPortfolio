## ¿Qué es Payload CMS?
- Por qué es el CMS preferido para desarrolladores JavaScript/TypeScript.
- La diferencia entre un CMS "GUI-first" y uno "code-first".

## Configuración y Primeros Pasos
- Instalación rápida con `npx create-payload-app`.
- Entendiendo el archivo de configuración central.

## Construyendo las bases: Colecciones y Globals
- **Colecciones**: Gestionando datos repetitivos (Posts, Usuarios).
- **Globals**: Datos únicos (Configuraciones, Menús).
- Tipos de campos avanzados y el editor Lexical.

## Control de Acceso y Hooks
- Cómo proteger tu API de forma granular.
- Hooks para automatizar acciones antes y después de guardar datos.

## Integración con el ecosistema moderno
- Consumo de la API vía REST y GraphQL.
- Plugins oficiales y de la comunidad.

## Conclusión
Payload CMS ofrece una flexibilidad inigualable sin sacrificar la experiencia del desarrollador.
