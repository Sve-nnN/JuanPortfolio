# Frontend Routes

This folder contains the frontend routes of the website. It uses the Next.js App Router.

## Files

- **globals.css:** Contains global CSS styles.
- **layout.tsx:** The root layout for the frontend.
- **not-found.tsx:** The 404 not found page.
- **page.tsx:** The main entry point for pages.

## Folders

- **(sitemaps):** Contains sitemap generation logic.
- **[slug]:** The catch-all route for dynamic pages.
- **author:** The author page.
- **authors:** The authors listing page.
- **blog:** The blog listing page.
- **case-studies:** The case studies listing page.
- **home:** The home page.
- **next:** Next.js specific files.
- **posts:** The blog post page.
- **search:** The search results page.
